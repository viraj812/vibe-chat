# 💬 Vibe Chat

**Vibe Chat** is a real-time web-based chat platform that connects two random strangers to engage in anonymous conversations. The project is built from scratch, including both the front-end website and the back-end chat server.

## 🚀 Features

- 🔀 Matchmaking system to pair random users
- 💬 Real-time text chat
- ⏱️ Instant connection and disconnection
- 🕶️ Anonymous and private
- 🌐 Fully responsive web interface

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js
- **WebSockets:** SocketIO
